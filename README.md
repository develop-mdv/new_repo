\# Учебный проект по работе с Git



Проект для изучения Git, совместной разработки и GitHub Actions.



\## Программы



\- prog1.py — обмен значений двух переменных.

\- prog2.py — вычисление длины строки с обработкой отсутствующего ввода.

\- prog3.py — вывод приветствия.



\## Требования



Git и Python 3.12. Дополнительные библиотеки не требуются.



\## Получение проекта



```bash

git clone https://github.com/develop-mdv/new\_repo.git

cd new\_repo

git switch release

```



\## Запуск



Выполняйте команды из корневой папки проекта:



```bash

python prog1.py

python prog2.py

python prog3.py

```



Для prog2.py введите строку и нажмите Enter.



\## Тестирование



```bash

python -m unittest discover -s tests -v

```



Шесть интеграционных тестов проверяют обмен переменных,

обработку строк и вывод приветствия.

При успешном выполнении выводится OK.



\## Непрерывная интеграция



Workflow находится в .github/workflows/main.yml.

При push и Pull Request автоматически проверяются синтаксис,

запуск программ и интеграционные тесты.

Результаты доступны во вкладке Actions на GitHub.



\## Ветки и версии



\- main — основная ветка.

\- development — разработка функций и исправлений.

\- release — подготовка выпуска.

\- dev1, dev2, dev3 — учебные ветки участников.

## Генерация документации

Локальная сборка:

```bash
python build_docs.py
```

Результат находится в docs/index.html.

CI автоматически собирает документацию при каждом push
и обновлении Pull Request. HTML доступен для скачивания
в разделе Artifacts соответствующего запуска GitHub Actions.



Версия указана в VERSION, изменения — в CHANGELOG.md.

Тег v1.0.0 фиксирует состояние первого выпуска.
